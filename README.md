# Интеллектуальные технологии и системы · маршрут студента

Интерактивная карта осеннего семестра: последовательные лабораторные, параллельный трек курсовой, условия межсессионной аттестации и допуска к экзамену.

## Локальный просмотр

```bash
npm install
npm run dev
```

После запуска страница доступна по адресу `http://localhost:3000`.

## Сборка и размещение

```bash
npm run build
```

Проект подготовлен для OpenAI Sites / Cloudflare. Перед публикацией задайте переменную `NEXT_PUBLIC_SITE_URL` с публичным адресом сайта — она нужна для корректной карточки предпросмотра.

Прогресс студентов хранится локально в браузере и не требует базы данных.
